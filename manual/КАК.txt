Ручная установка. Питон не нужен.

Если нужен ещё набор плагинов (https://github.com/posolware1/nympri-plugins), сначала поставьте его, потом этот русский патч. Ручная установка плагинов останавливается, если в plugins.js уже есть NP_.

Это патч русского текста для Nymphomania Priestess Alpha 0.80j (Windows).
Папка игры — та, где лежит Game.exe. Внутри неё папка www.
Папку www\save не открывайте и не копируйте.
Не копируйте весь архив в игру.
Не подменяйте plugins.js другим файлом целиком.

Этот патч заменяет английские файлы текста русскими.
Сначала сделайте свои копии. Эти шаги не хранят старый текст.
Файл plugins.js.manual-bak потом возвращает список плагинов. Он не возвращает английские csv и System.json.

1. Распакуйте весь ZIP в обычную папку. Не работайте внутри окна архива.
2. На рабочем столе создайте папку NymPri-backup.
3. Скопируйте в неё папку www\csv игры. Копируйте всю папку csv, вместе с папкой npc внутри.
4. Скопируйте туда же файл www\data\System.json игры.
5. Откройте www\js игры. Если там уже есть plugins.js.manual-bak, не заменяйте его и не удаляйте. Это прежняя копия списка плагинов.
6. Если plugins.js.manual-bak нет, скопируйте plugins.js и назовите копию plugins.js.manual-bak. Оставьте её в той же папке js.
7. Правой кнопкой по www\js\plugins.js игры → Открыть с помощью → Блокнот. Нажмите Ctrl+F и найдите NP_.
   Запомните, нашлось ли, и закройте блокнот без сохранения.
   - Ничего не нашлось: две строки вставите на шагах 12 и 13.
   - Нашлось NP_: ничего не вставляйте. Шаги 8–11 всё равно сделайте. Файлы текста всё равно нужно заменить.
8. Поднимитесь на папку вверх от этого файла, туда, где лежит install.bat. Откройте www. Выделите внутри четыре папки: csv, data, js, lang. Скопируйте.
9. Откройте www игры. В этом окне уже должны быть папки csv, data и js. Вставьте.
10. Если Windows спросит «Объединить папки?» — нажмите Да.
11. Если Windows спросит заменить файлы — нажмите «Заменить файлы в папке назначения».
    Заменить — правильная кнопка. csv и System.json — это русский текст. Пропустить оставит эти файлы английскими.
    Если решили по каждому файлу, на каждом жмите Заменить.
    Не удаляйте папки data и js игры перед вставкой. Заменится только System.json внутри data, а в js\plugins добавятся два скрипта. Остальные файлы там останутся.
    Новая папка lang — английский текст для кнопки RU | EN. Если Windows спросит заменить файлы внутри lang, тоже нажмите Заменить.
    NP_Language.js и NP_OptionsCategories.js входят в этот патч. Если Windows спросит заменить эти два файла, нажмите Заменить.
12. Только если на шаге 7 не было NP_:
    Откройте www\js\plugins.js игры в блокноте.
    Нажмите Ctrl+F и найдите MEO_Util_Node. Строка должна заканчиваться запятой. Если нет — допишите запятую. Поставьте курсор в начало следующей строки.
    Откройте manual\paste-after-MEO_Util_Node.txt. Нажмите Ctrl+A, скопируйте и вставьте.
13. Только если на шаге 7 не было NP_:
    Пролистайте вниз, к строке ];
    Строка над ]; должна заканчиваться запятой. Если нет — допишите запятую. Поставьте курсор в начало строки ];.
    Откройте manual\paste-at-end.txt. Нажмите Ctrl+A, скопируйте и вставьте.
    Нажмите Ctrl+S и закройте блокнот.
14. Если на шаге 7 было NP_, не вставляйте текст. Откройте plugins.js и проверьте два места. Следующее имя после MEO_Util_Node — NP_Language. Последнее имя перед ]; — NP_OptionsCategories. Если не так, закройте без сохранения. Не чините это вставкой. Запустите install.bat (для него нужен Python).
15. Проверка до запуска игры:
    - Есть файл www\js\plugins\NP_Language.js.
    - Есть файл www\js\plugins\NP_OptionsCategories.js.
    - Есть файл www\lang\en\build_info.json.
    - Откройте www\data\System.json в блокноте. Нажмите Ctrl+F и найдите Уровень. Блокнот должен найти это слово.
    - Откройте www\csv\status.csv в блокноте. Нажмите Ctrl+F и найдите Раса. Блокнот должен найти это слово.
    - В plugins.js имя NP_Language стоит сразу после MEO_Util_Node.
    - Последнее имя перед ]; — NP_OptionsCategories.
    - Папка www\save на месте, вы её не копировали.
16. Запустите игру. Язык — русский. В настройках есть «Язык / Language». На титуле есть кнопка RU | EN.

Как вернуть как было
1. Закройте игру.
2. Скопируйте NymPri-backup\csv обратно в www игры. Когда Windows спросит, нажмите Заменить. Так вернутся английские таблицы.
3. Скопируйте NymPri-backup\System.json обратно в www\data игры. Нажмите Заменить.
4. Скопируйте www\js\plugins.js.manual-bak поверх www\js\plugins.js. Нажмите Заменить. Так вернётся список плагинов. Текст это не возвращает. Текст возвращают шаги 2 и 3.
5. Удалите папку www\lang. Так уйдут дополнительные английские файлы этого патча.
6. Файлы NP_Language.js и NP_OptionsCategories.js можно оставить в www\js\plugins. Без строки в списке они не запускаются. Удаляйте эти два файла только если вы не пользуетесь отдельным набором плагинов. Если пользуетесь им, файлы оставьте и верните список плагинов из того набора, а не этот manual-bak.

install.bat хранит такую же копию списка, с именем plugins.js.bak, и только первую. Повторный запуск её не заменяет. В этом файле нет старых csv и System.json.
