Nymphomania Priestess Alpha 0.80j — патч русской локализации + переключатель языка
Сборка патча: 2026-11-05

ЧТО ЭТО
Лёгкий патч ПОВЕРХ английской оригинальной папки www (версия Alpha 0.80j).
Не включает Game.exe, аудио, картинки, видео и прочие ассеты — только перевод,
оверлей EN для обратного переключения и два плагина.

ТРЕБОВАНИЯ
• Оригинал: Nymphomania Priestess Alpha Ver.0.80j (английская www).
• Не ставьте поверх полной русской сборки с модом — это другой пакет.

УСТАНОВКА
1. Сделайте копию всей папки игры (или хотя бы www\csv, www\data\System.json,
   www\js\plugins.js и www\js\plugins\).
2. Распакуйте архив патча.
3. Содержимое папки www\ из патча скопируйте в www\ вашей игры с заменой файлов:
     www\csv\*.csv          — русские таблицы (диалоги, предметы, квесты…)
     www\data\System.json   — русские термины меню/боя (остальное из оригинала)
     www\lang\en\           — английский оверлей для переключения обратно на EN
     www\js\plugins\NP_Language.js
     www\js\plugins\NP_OptionsCategories.js
4. Подключите плагины в www\js\plugins.js одним из способов:

   А) Автоматически (рекомендуется):
      python patch_plugins_js.py "C:\path\to\game\www\js\plugins.js"
      (создаст plugins.js.bak)

   Б) Вручную — см. plugins_fragment.txt:
      • Сразу ПОСЛЕ строки с MEO_Util_Node вставьте запись NP_Language.
      • В КОНЕЦ списка плагинов (перед закрывающей ];) добавьте NP_OptionsCategories.
      • NP_Language обязан стоять сразу после MEO_Util_Node (до читателей CSV).
      • NP_OptionsCategories — последним (категории настроек; без него язык
        всё равно доступен в Настройках и кнопкой RU|EN на титуле).

5. Запустите игру. Язык по умолчанию: Русский.
   Переключение: Настройки → «Язык / Language» или кнопка «RU | EN» на титуле.
   После смены игра перезапускается (location.reload). Выбор пишется в config.rpgsave.

ЧТО ПЕРЕЗАПИСЫВАЕТСЯ
• Перечисленные csv (см. FILELIST.txt) — полная замена файлов.
• data\System.json — термины UI на русский; BGM титула, свитчи/переменные
  оригинала сохранены (без меток мода).
• Новые файлы: lang\en\*, js\plugins\NP_Language.js, NP_OptionsCategories.js.
• plugins.js — только две добавленные строки (при ручном/скриптовом патче).

КАК РАБОТАЕТ RU/EN
• Архитектура: русский — основной (csv + System terms).
• Режим EN: плагин читает www\lang\en\csv\ и накладывает data_overlay.json
  на JSON (в этом патче оверлей закрывает System/Map014-строки и общие фразы).
• Сохранения совместимы в обе стороны (структура событий не меняется этим патчем).

НЕ ВХОДИТ В ПАТЧ
• Плагины мода (бой, элитки, дневник, квесты Яризо и т.д.).
• Правки карт/CommonEvents мода, новые предметы в data\Items.json и т.п.
• Полная русская сборка с Game.exe — см. отдельный релиз на Диске.

ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ
• Основной объём перевода — CSV (sheet/commonSheet/logsheet/квесты/БД).
  Отдельные редкие строки в картах/CE оригинала могут остаться на EN/JP.
• EnemyData.csv в EN-оверлее нет (функциональные правки) — в EN-режиме
  используется русский файл (текст там почти не отличается).
• NP_OptionsCategories рассчитан на наличие других NP_* опций; на чистом
  оригинале просто добавит категорию «Язык и текст» — это нормально.

ОТКАТ
Восстановите бэкап www (или отдельные csv / System.json / plugins.js.bak)
и удалите www\lang\en, NP_Language.js, NP_OptionsCategories.js.
